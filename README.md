# রোগী অভিজ্ঞতা ও হেলথ কম্যুনিটি (React + Vite)

## চালানোর নিয়ম
1. Node.js (v18+) ইনস্টল করুন: https://nodejs.org
2. ZIP আনজিপ করে VS Code-এ ফোল্ডারটি খুলুন (File > Open Folder)
3. Terminal খুলুন (Ctrl + `) এবং চালান:
   npm install
   npm run dev
4. ব্রাউজারে http://localhost:5173 খুলুন

প্রোডাকশন বিল্ড: npm run build

## ফাইল
- src/App.jsx  : পুরো অ্যাপ (লগইন+OTP, ফিড, কমেন্ট, চ্যাট, নোটিফিকেশন, গর্ভাবস্থা, টেস্ট গাইড, বিশেষজ্ঞ প্যানেল)
- src/data.js  : নমুনা ডেটা (পোস্ট, ক্যাটাগরি, গাইড)
- src/index.css: স্টাইল

## নোট
এটি ফ্রন্টএন্ড ডেমো। OTP, চ্যাট ও নোটিফিকেশন ব্রাউজারে সিমুলেটেড; রিফ্রেশ করলে ডেটা মুছে যায়।
আসল ব্যবহারের জন্য ব্যাকএন্ড (Firebase/Supabase) যুক্ত করতে হবে।
